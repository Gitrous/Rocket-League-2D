# Rocket League 2D

Fútbol con coches en 2D que se juega en el navegador. Las físicas vienen del juego de GameMaker
[2D Rocket League](https://github.com/cedricholmgren/2D-Rocket-League).

Para jugar, abre `index.html` en el navegador. No hace falta instalar nada.

## Pantallas

1. **Ajustes:** físicas del coche y de la pelota, IA activada (1 jugador) o desactivada (2 jugadores) y volumen.
2. **Garaje:** carrocería, ruedas, color y estela del turbo de cada jugador.
3. **Estadio:** marcador, Restart y Back.

## Controles

| | Jugador 1 | Jugador 2 |
|---|---|---|
| Mover / girar en el aire | A / D | ← / → |
| Saltar (doble salto en el aire) | W | ↑ |
| Turbo | Mayús izquierda o Espacio | Mayús derecha |
| Frenar | S | ↓ |

Enter: Play! · Esc: Back · F: pantalla completa.
